# Demonstration script

1. Start the API and frontend with the local instructions.
2. Review the seven seeded claims and filter first for `contradicted`, then for `unresolved`.
3. Open the Earth orbital-period claim and inspect the NASA title, URL, access date, evidence passage, and scope.
4. Compare the 365.25-day orbital claim with the claim that Earth rotates once every 365.25 days.
5. Leave the current-version claim unresolved because the record contains no up-to-date release evidence; inspect the report.

**Expected behavior:** The example corpus includes supported, contradicted, unresolved, and not-checkable verdicts; source coverage is 5/7 (0.714). No missing citation is automatically treated as proof of falsity.
